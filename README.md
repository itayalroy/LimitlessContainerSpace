# Enhanced Blood Trail

This is a mod for **The Long Dark** by Hinterland Games Studio, Inc. It enhances animal blood trails to make tracking wounded animals easier and more realistic.

## Features

- **Larger Blood Stains**: Blood stains are 3x larger and more visible (1.5x opacity)
- **More Blood Drops**: Animals leave twice as many blood drops when bleeding
- **Longer Lasting Trails**: Blood decals persist for 1 hour (3600 seconds) instead of disappearing quickly

This makes tracking wounded animals much easier, especially in snowy conditions.

## Installation

1. If you haven't done so already, install MelonLoader by downloading and running [MelonLoader.Installer.exe](https://github.com/HerpDerpinstine/MelonLoader/releases/latest/download/MelonLoader.Installer.exe).
2. Download the latest version of `EnhancedBloodTrail.dll` from the releases page.
3. Move `EnhancedBloodTrail.dll` into the Mods folder in your TLD install directory.

## Configuration

The multipliers are currently hardcoded:
- Blood stain size: 3x
- Blood stain opacity: 1.5x (capped at 1.0)
- Blood cluster count: 2x
- Decal lifetime: 3600 seconds (1 hour)

Future versions may include a configuration file to adjust these values.
